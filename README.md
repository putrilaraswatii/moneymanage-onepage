# UMKM Tertib Keuangan — One Page Final

Versi final satu halaman yang ditujukan untuk pelaku UMKM, termasuk pengguna yang masih terbiasa dengan pencatatan sederhana secara manual.

## Arah desain
- Sederhana, hangat, mudah dibaca, dan tidak terlalu teknis.
- Menggunakan warna dasar krem hangat dengan hijau sebagai warna utama, cokelat sebagai penanda struktur, dan terracotta sebagai aksen.
- Kartu dan tombol digunakan seperlunya agar website tidak terlihat polos tetapi juga tidak penuh pilihan.
- Responsive untuk ponsel dan desktop.

## Isi
1. Beranda
2. Landasan pemisahan keuangan
3. Langkah penerapan
4. Buku Kas + contoh + template Excel
5. Simulasi interaktif
6. Tentang website

## File
- `index.html` — seluruh konten website.
- `style.css` — desain dan responsive layout.
- `script.js` — simulasi dan tahun footer.
- `template-buku-kas-umkm.xlsx` — template Excel siap diunduh.

Tidak ada poster di dalam website. Website bukan aplikasi dompet digital, kasir, perbankan, atau software akuntansi penuh.
